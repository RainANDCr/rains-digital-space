# 阶段 04：数字造物所

范围：复用 11 个项目，增加本地搜索、技术标签组合筛选、网格/时间线切换、稳定项目详情 URL；首页精选作品链接到对应详情。只在本地运行，不提交、不推送、不部署。

修改：Projects、App 路由/元数据、Home 精选入口、filterProjects、双语资源、world.css；新增 ProjectDetail、网站项目的可选档案字段及针对性测试。

技术选择：使用现有 React Router URLSearchParams 管理列表状态，关键词修改替换当前历史项，筛选/视图切换保留 URL 条件。详情返回列表携带原查询参数。可直接打开 /projects/:id，并兼容原 /projects。

保护：id 不改；原数据字段不迁移；保留分类、GitHub/Demo、原说明、双语、主题、Markdown 与全部旧 URL。未填的日期放在时间线末尾，不能生成假的开发顺序。图库使用已存在的项目介绍插画，并明确说明不是应用截图。

详情字段：archive 可选，包含 story、features、log、next；老项目不填仍可展示完整基本档案。仅网站项目补充本次实际实现的内容；不编造个人职责、历史进度或其他项目成果。

验证：筛选函数兼容旧调用、搜索大小写与双语组合、URL/刷新/返回、详情未知 ID、手机与双主题、构建。未访问外站或测试其他项目本身。
