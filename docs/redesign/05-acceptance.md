# 阶段 05 本地验收

## 实现

- 新增按需加载 `/travel`，顶部导航与首页章节都可进入，保留原 `/#journal` 和既有文章 URL。
- 地图/列表、年份/城市/主题组合筛选、城市明信片、可选关联文章与相册。地图是原创 SVG 经纬度示意图，无真实地理底图；不需要地图服务、定位、密钥或新依赖。可随时切换列表。
- `journeys` 为空，仅展示确认且公开的条目。原有旅行文章保留为文字入口，不推断成真实到访记录。

- 中英文、深浅主题、减少动态效果与手机适配；旅行 title/description/OG 随语言切换。

新增 Travel、PhotoGallery、travel.js 数据/工具、travel.css、测试夹具与本阶段文档。修改 App、Layout、Home、world、双语资源、测试及 README。没有修改部署配置或引入依赖。
