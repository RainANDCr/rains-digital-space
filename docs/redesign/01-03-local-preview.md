## 人工验收

1. 点击“开启旅程”，进入章节目录；点旅行手记，到已有文章入口；点文章，打开原详情页。
2. 使用顶部 About/Contact 锚点、项目和博客导航，切换主题/语言并刷新。
3. 手机菜单展开、选择链接、按 Escape；在减少动态效果设置下确认所有入口仍可使用。
4. 文章仍为中文原文，英文 UI 明示原语言，没有生成伪译文。
